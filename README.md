# Professor Ai Studio — Online VoxCPM2 Voice Vault

Official cloud voice stem catalog for **Professor Ai Studio** (VoxCPM2 48 kHz Zero-Shot Voice Cloning).

- **Catalog Version:** `v2.0.0`
- **Total Voices:** 411 stems (84.71 MB)
- **Format:** Original lossless `.wav` & reference `.mp3` stems (zero re-encoding)
- **App Integration:** Open **Settings → VoxCPM2 Neural AI → Reference Stem Vault** to stream-preview online, download individual voices, or sync all voices with 1 click.
